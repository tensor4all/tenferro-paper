# tenferro-rs JOSS paper (draft)

Private working repository for the JOSS submission of
[tenferro-rs](https://github.com/tensor4all/tenferro-rs).

- `paper/paper.md`, `paper/paper.bib`: the manuscript (JOSS format).
- `paper/figure_benchmark.png`: generated by `python3 scripts/make_figure.py`
  from the tables in `data/`.
- `paper/figure_architecture.png`: rendered from `tenferro-rs/docs/assets/tenferro-architecture.svg`.
- `data/`: verbatim copies of tenferro-benchmark reports (mac CPU 2026-08-12, NVIDIA GPU 2026-08-22, AMD CPU 2026-07-28).
- `.github/workflows/draft-pdf.yml`: builds `paper.pdf` with the official JOSS action on every push (download from the Actions artifacts).
